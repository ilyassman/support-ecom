# Support E-commerce - Full Stack Application

Application de support client e-commerce avec chatbot IA intégré.

## 🚀 Technologies

### Backend
- Python 3.11+
- FastAPI
- Google Gemini AI
- Uvicorn

### Frontend
- React 19 + TypeScript
- Vite
- Framer Motion
- Axios

## 📦 Installation locale

### Backend
```bash
cd ecommerce-support-chat-backend
pip install -r requirements.txt
cp .env.example .env
# Ajouter votre GEMINI_API_KEY dans .env
python main.py
```

### Frontend
```bash
cd ecommerce-support
npm install
npm run dev
```

## 🌐 Déploiement

- **Frontend**: Déployé sur Vercel
- **Backend**: Déployé sur Render
